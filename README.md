# Amity Arcade — game releases

Release notes for the games in Amity's Arcade (Breach Strike, Siege Protocol, Nitro Kart Rivals, Amity Sports).
Each release is tagged `<game>@<version>` and published by the games' `promote` step; the Amity app reads them to show
each game's "What's new" and the news on Início. The builds themselves are served by the games CDN, not from here.
